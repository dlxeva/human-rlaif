## 验收还需要什么

R3 已在手工加载的合成三轮响应中观察到启动；真实使用者可用性仍待检验。R5 新会话开头实际查到期与 R7 英文自动触发仍需要宿主独立运行。手工把 SKILL 放进提示词只能检查指令条件下响应，不能冒充自动发现/触发。不得为跑测试安装到真实用户技能目录。

blocked 表示「前置条件不足，尚未完成」，不计为通过。fork_turns 是是否继承父会话历史的运行设置；CODEX_HOME 是 Codex 存放配置、状态与认证信息的目录。测试不可借用真实私人认证或记录。

历史证据保留核对见 [逐文件哈希](historical-preservation.json)：12 个原 run 文件中，10 个证据文件字节不变；2 个 README 仅增加导读，原文与计数保留。
