# 术语表 / Glossary

| 术语 / Term | 白话含义 / Plain meaning |
|---|---|
| 训练坐标 / Responsibility target | 想练习承担哪种结果责任，不是已取得职位、资质或权限。The responsibility you want to practice, not a credential or permission. |
| 人类参与规范 / Human participation agreement | 人承诺真实表达、说明判断与取舍、带回现实结果；AI 起草，人确认。A human-confirmed agreement about honest input, decisions, and follow-through. |
| 独立首稿 / Independent first draft | 看见目标答案或提示前保存的本人原始判断。The original human attempt saved before target-specific help. |
| 辅助污染 / Assistance contamination | AI 示例、旧答案或策略提示提前影响了本应独立的作答。Prior help leaked into an attempt intended to be independent. |
| 隔离 / Isolation | 旧答案、提示和记忆是否对评估作答可见；clean、partial、contaminated、unknown 分别为干净、部分、已污染、未知。How much prior help is visible during assessment. |
| 基线 / Baseline | 后续比较用的初始行为样本，不是人格或通用能力等级。An initial sample for later comparison. |
| 召回 / Recall | 先自己回想旧判断的理由和条件，再看原记录。Remember the reasoning before reopening the notes. |
| 摩擦 / Cognitive challenge | 一项能暴露判断缺口的证据、反例或取舍问题，不以难受或改口为目标。One useful challenge, not discomfort for its own sake. |
| 协作控制 / Collaboration control | 人能设目标、识别 AI 错误、拒绝建议、决定取舍和验收结果。Keeping control of goals, AI advice, trade-offs, and acceptance. |
| 预测校准 / Forecast calibration | 对一件会不会发生的事，事先写概率，再与实际结果对照。Compare an advance probability with what actually happens. |
| Brier 分数 / Brier score | 二元事件的平均 `(概率 − 结果)²`，概率用 0–1，结果用 0/1；越低越好。Mean squared probability error; lower is better. |
| 命中率 / Hit rate | 按预先固定的方向规则猜中的比例；报告分母，不能代替概率校准。Fraction of correct directional forecasts, with a stated denominator. |
| 延迟复测 / Delayed retest | 间隔一段时间后用新材料再试，检查是否保持或能迁移。Try new material later to check retention or transfer. |
| 迁移 / Transfer | 能否把同一种判断能力用到不同材料或情境。Use the skill in a new context. |
| 盲评 / Blind review | 评阅者按已锁标准评价，不知道原先 AI 结论或条件标签；做到哪层就说哪层。Review without prior verdicts or condition labels; state the actual blinding. |
| 待验证 / Pending | 尚无足够结果或证据，不能按失败、成功或零分填补。Unresolved, not an assumed success, failure, or zero. |
| 训练 / Training | 本项目中指人的练习和反馈循环，不执行模型训练。Human practice and feedback, not model optimization. |
